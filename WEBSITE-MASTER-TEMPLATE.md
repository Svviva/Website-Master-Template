# Website Master Template

Reusable bilingual English/Arabic school website foundation.

## Purpose
Use this branch as the starting point for future school website projects. Do not develop a new school's website directly on the Sarh Al Elm `main` branch.

## Preserved reusable features
- English and Arabic page structure
- RTL Arabic support
- Responsive desktop and mobile layouts
- Mobile navigation and language switching
- Accessible subtle scroll animations and reduced-motion support
- Home, About, Academics, School Life, Admissions, Gallery, News and Contact page structures
- WhatsApp contact pattern
- Map/contact section
- Gallery structure
- SEO and accessibility foundations

## New school setup checklist
Before publishing a new school website, replace and verify:

1. School name in English and Arabic
2. Logo and brand colours
3. Address and map
4. Telephone and WhatsApp numbers
5. Email address
6. Social-media links
7. Principal name, photograph and approved welcome message
8. Genuine school photographs and captions
9. Grade levels
10. Curriculum and academic claims
11. Admissions requirements, fees and procedures
12. School-life activities and facilities
13. News and announcements
14. Any school portal/login link
15. Domain name and hosting configuration

## Content rule
Never carry factual claims from one school into another school without verification. English and Arabic pages should communicate the same verified facts while using natural language in each language.

## Photography rule
Use photographs supplied or approved by the new school. Replace the existing project photographs before publishing for another school.

## Branch workflow
For each new school, create a fresh project branch or repository from `website-master-template`, then customize and test that copy. Keep this master branch generic and reusable.
